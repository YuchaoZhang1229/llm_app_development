# Python 学习重点清单（AI 应用 / Agent 开发方向）

> 从 15 个模块中提炼的「学习重点」，按投入产出比分三档。
> 判据唯一：**该知识点在 LangChain / LangGraph 源码中是否高频出现。**

---

## 一档 · 必吃透（⭐⭐⭐ 9 个胜负手）

| 知识点 | 来自模块 | 为什么是重点 |
|--------|---------|-------------|
| dict 操作 + 推导式 | 02 数据结构 | LangChain 的消息、Tool 参数、LangGraph State 全是 dict，唯一"天天摸"的数据结构 |
| 继承重写 + `__call__` | 04 面向对象 | 框架用法就是"继承 BaseTool / BaseModel 重写方法"，`llm.invoke()` 背后就是 `__call__` |
| 生成器 / 迭代器 | 05 高级特性 | 逐 token 输出（`stream` / `astream`）的底层机制，不懂生成器就看不懂流式 |
| 装饰器 | 05 高级特性 | `@tool`、`@retry`、`@cache` 全部是装饰器，还要会写带参数的装饰器 |
| 异常重试模式 | 06 异常处理 | 调 LLM API 必踩超时 / 限流，"捕获 → 重试 → 降级"是生产 Agent 的日常 |
| asyncio 异步 | 12 补充 | `astream` / `ainvoke` / `gather` 全靠它，不会异步 = 只能单线程傻等 |
| typing（TypedDict） | 13 补充 | LangGraph 定义 State 的标准写法，不会就写不了图 |
| Pydantic | 14 补充 | Structured Output + Tool 参数 Schema + API Key 配置，三处全靠它 |
| HTTP 调用 | 11/15 | 理解"模型调用 = 一次 HTTP 请求"这个本质，SSE 流式 = HTTP 版生成器 |

## 三档 · 了解即可（⭐ 别花大时间）

| 知识点 | 来自模块 | 说明 |
|--------|---------|------|
| socket 底层 | 11 网络编程 | 知道 TCP / UDP 概念即可，Agent 开发几乎用不到 |
| 多进程 multiprocessing | 10 并发 | 懂选型逻辑即可，实际 Agent 场景 asyncio 主导 |
| 多继承 / 元类 metaclass | 04 面向对象 | 极少数框架源码用到，先跳过 |
| 正则 re 深度 | 09 标准库 | 够用即可（数据治理背景可稍重，但别钻牛角尖） |
| logging 高级配置 | 09 标准库 | 会打分级日志就够 |

---

## 最小核心清单（时间紧只抓这 5 个）

> **dict/推导式 → 生成器 → 装饰器 → asyncio → Pydantic**

| 顺序 | 知识点 | 在链路中的角色 |
|------|--------|---------------|
| 1 | dict / 推导式 | 数据载体 |
| 2 | 生成器 | 流式输出 |
| 3 | 装饰器 | 工具封装 |
| 4 | asyncio | 并发调度 |
| 5 | Pydantic | 结构化出入口 |

这五个是一条完整链路，吃透后接 LangChain 基本无痛。

---

## 一句话结论

**路线图没错，但"重点"排序时：第 2 层（05）和第 4 层补充（12-15）里的这 9 个知识点，投入产出比最高，优先砸时间。**
